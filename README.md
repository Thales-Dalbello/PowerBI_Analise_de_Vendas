# PowerBI_Analise_de_Vendas
💰 Relatório de Análise de Vendas

Este projeto apresenta um painel de Business Intelligence desenvolvido com Power BI, com o objetivo de analisar o desempenho geral de vendas da empresa ao longo do ano. O relatório permite monitorar indicadores importantes como receita total, pedidos realizados, itens vendidos, média por pedido, desempenho por colaborador, entre outros.
Segue link para acesso ao relatorio: https://app.powerbi.com/view?r=eyJrIjoiMDlkY2Q0ODUtNzNjOS00ZjVjLWIyYjktNzU3ZDkwODRiZTMzIiwidCI6Ijg1ZGU1OTA5LTZlOGItNGEwYy1iYTIzLWYwMzYyYzcyZDc3NiJ9

📊 Funcionalidades

    Filtros interativos por loja e estado

    Receita total e média por pedido

    Número total de pedidos e quantidade de itens vendidos

    Gráfico de linha com o comportamento de vendas por mês

    Ranking de vendas por colaborador

    Análise de quantidade de vendas por tipo de produto

🧠 Insights Possíveis

    Identificação dos meses de pico e queda nas vendas

    Colaboradores com melhor desempenho comercial

    Produtos com maior e menor volume de vendas

    Análise regional e por loja para planejamento de estratégias comerciais

🛠️ Tecnologias Utilizadas

    Power BI

    Microsoft Excel (arquivo: Análise de Vendas.xlsx) como fonte de dados
